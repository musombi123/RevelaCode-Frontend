# Security Policy

## Supported Versions

RevelaCode is an actively evolving project. Security updates will primarily focus on the most recent stable version of the application.

Older versions may not receive security updates.

---

## Reporting a Vulnerability

If you discover a security vulnerability within the RevelaCode project, please report it responsibly.

Do not publicly disclose the vulnerability through GitHub issues or discussions until it has been reviewed and addressed.

Instead, contact the project maintainer with the following information:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Any potential impact
- Suggested fixes (if available)

This allows the issue to be investigated and resolved before public disclosure.

---

## Responsible Disclosure

We ask security researchers and contributors to practice responsible disclosure.

Once a vulnerability has been confirmed and fixed, maintainers may publish a summary of the issue so the community can stay informed.

---

## Security Best Practices

Contributors should follow common security practices when working on the project:

- Avoid exposing sensitive information
- Do not commit secrets or API keys
- Validate inputs where appropriate
- Keep dependencies updated

Maintaining secure code helps protect both the project and its users.

---

## Commitment

Security is an important part of maintaining trust in any software project.

The RevelaCode project will make reasonable efforts to investigate and address reported vulnerabilities in a timely manner.
